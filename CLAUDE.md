# CLAUDE.md

This file provides guidance to Claude Code (claude.ai/code) when working with code in this repository.

## Commands

```bash
npm run dev      # Start dev server at http://localhost:3000
npm run build    # Static export to out/
npm run start    # Serve production build locally
npm run lint     # ESLint via Next.js
```

There are no tests. The `out/` directory is git-ignored and generated by `npm run build`.

## Deployment

Pushing to `main` triggers GitHub Actions (`.github/workflows/deploy.yml`), which builds and deploys the `out/` directory to the `gh-pages` branch. GitHub Pages serves from `gh-pages` at `https://jenghua.github.io/drag`.

**Production vs dev path**: `next.config.js` sets `basePath: '/drag'` and `assetPrefix: '/drag'` only when `NODE_ENV=production`. All image `src` and CSS `url()` references use `process.env.NEXT_PUBLIC_BASE_PATH` (empty in dev, `/drag` in prod).

## Architecture

Single-page Next.js 14 App Router app. No API routes, no server components beyond the layout.

```
app/layout.js        # Root layout: injects @font-face <style> with correct basePath paths
app/page.js          # Dynamically imports DragEditor with ssr:false (react-draggable requires browser)
app/globals.css      # Tailwind directives only — no @font-face here
components/DragEditor.js  # 'use client' — all app logic lives here
public/              # Fonts (.ttf/.otf) and images served as static assets
```

### Font loading

Custom fonts are declared as `@font-face` in `app/layout.js` (not CSS) so the `NEXT_PUBLIC_BASE_PATH` prefix can be injected at build time. Three small English fonts are `<link rel="preload">`-ed in the same layout. On component mount, `document.fonts.load()` is called for all five fonts in the background to pre-warm the large Chinese fonts (~35 MB each).

### Download (Canvas API)

The download button does **not** use html2canvas. It uses the native Canvas API to manually reproduce the output:
1. `await document.fonts.ready` — ensures fonts are loaded before drawing
2. Draws `drag.png` background with manually computed `background-size: contain` geometry
3. Draws text at `position.x / position.y` (react-draggable offsets), rotating around the text element's center to match CSS `transform-origin: 50% 50%`

If the downloaded image doesn't match the preview, check the `position`, `rotation`, `fontSize`, and `fontFamily` values passed to `handleDownload`'s `useCallback` dependency array.

### Key constraints

- `public/index.html` must **not** exist — Next.js static export copies `public/` into `out/`, which would overwrite `out/index.html`.
- `react-draggable` requires `nodeRef` to avoid deprecated `findDOMNode` warnings; always pass a `useRef` to both `nodeRef` and the direct child.
- Font files in `public/` are served at `/drag/font.ttf` on GitHub Pages — never hardcode `/font.ttf` absolute paths.
